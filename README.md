# JCVI-syn3A Genome Explorer

### View the live site: https://syn3a-explorer.vercel.app

An interactive website based on David Goodsell's JCVI-syn3A illustration — the first illustration to depict an entire proteome. Hover or click shapes in the cell to see which gene(s) encode them.

## Attribution

This project is an adaptation of David Goodsell's original illustration: individual proteins have been traced and linked to genome data to create the hover/click exploration.
